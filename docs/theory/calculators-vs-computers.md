# Calculators vs computers

* **Calculator:** fixed-function device built around arithmetic; the operation set is hard-wired or in a tiny fixed ROM; the user cannot load arbitrary programs (programmable calculators are a limited exception).
* **Computer:** general-purpose, stored-program machine; instructions and data live in memory, so behavior is changed by software. It has a CPU (ALU + control), memory hierarchy, and I/O.
* Both contain an ALU; the difference is the control and memory architecture: a computer fetches, decodes and executes arbitrary instruction sequences (including branches), a calculator runs a fixed key-driven routine.

| | Calculator | Computer |
|---|---|---|
| Programmability | None / very limited | Fully programmable |
| Memory | A few registers | Large addressable memory |
| Purpose | Arithmetic/scientific functions | Any computable task |
